A [make.fun](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) bounty entry: a Node program that writes a single one-line cat joke (under 200 characters) to `/output/entry.txt`.

## The joke

> My cat ignores me all day, then at 3am sits on my chest and stares into my soul like a tiny landlord doing an inspection.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22+, standard library only. The output is deterministic — every run writes the exact same 121-character line.
